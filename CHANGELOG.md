# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [semantic versioning](https://semver.org).

## [1.3.1] - 2026-11-09

### Fixed

- The settings window showed **Auto** as the default while badges actually used **Views**. Both now read the same defaults from `defaults.js`.

### Changed

- The "Rate against" options are now named **Views**, **Views, else followers** and **Followers**.
- First public release: README, AGENTS.md for AI coding tools, privacy notes, tests for the manifest and settings, and an MIT license.

## [1.3.0]

- Engagement badges on X, Instagram (Reels tab, feed, post page, reel viewer) and the YouTube watch page.
- Reach chip, colour tiers, tooltips with every count, and opt-in Instagram follower lookups.
